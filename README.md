# Bank Account Simulation

## Description

A console-based Java application that simulates basic banking operations using Object-Oriented Programming (OOP) concepts.

## Features

- Check account balance
- Deposit money
- Withdraw money
- View transaction history
- Menu-driven banking operations

## Technologies Used

- Java
- Object-Oriented Programming (OOP)
- Classes and Objects
- Methods
- Exception Handling

## How to Run

1. Compile the program using `javac Main.java BankAccount.java`.
2. Run the program using `java Main`.

## Learning Outcomes

- Understanding Java OOP concepts
- Working with classes and objects
- Implementing deposit and withdrawal operations
- Maintaining transaction history
- Practicing exception handling
